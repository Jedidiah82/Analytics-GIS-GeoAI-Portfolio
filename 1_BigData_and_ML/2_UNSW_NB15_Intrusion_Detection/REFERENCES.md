# Dataset and methodological references

The [official UNSW-NB15 dataset page](https://research.unsw.edu.au/projects/unsw-nb15-dataset) documents the flow schema, nine attack categories, full-corpus record count, separate official train/test subset, acquisition links, attribution requirements, and research-use terms. This project does not redistribute dataset files. Consult the source terms for any proposed use.

The creators request citation of the following publications:

1. Moustafa, N. & Slay, J. (2015). *UNSW-NB15: a comprehensive data set for network intrusion detection systems (UNSW-NB15 network data set).* MilCIS. [Publisher record](https://ieeexplore.ieee.org/document/7348942).
2. Moustafa, N. & Slay, J. (2016). *The evaluation of Network Anomaly Detection Systems: Statistical analysis of the UNSW-NB15 data set and the comparison with the KDD99 data set.* Information Security Journal. See the official dataset page for the publisher link.
3. Moustafa, N. et al. (2017). *Novel geometric area analysis technique for anomaly detection using trapezoidal area estimation on large-scale networks.* IEEE Transactions on Big Data. See the official dataset page for the publisher link.
4. Moustafa, N. et al. (2017). *Big data analytics for intrusion detection system: statistical decision-making using finite dirichlet mixture models.* Data Analytics and Decision Support for Cybersecurity, pp. 127–156. See the official dataset page for the publisher link.
5. Sarhan, M., Layeghy, S., Moustafa, N. & Portmann, M. *NetFlow Datasets for Machine Learning-Based Network Intrusion Detection Systems.* [Authors' paper](https://arxiv.org/abs/2011.09144).

The executed rerun uses the owner's original-format local extract, not the separately published 175,341/82,332-row benchmark partition. Its January-to-February split is a project-specific temporal evaluation, not a claimed official benchmark result.
