# 🗺 AFENET Liberia Program Footprint (2020–2024)

## Overview
GIS and spatial analytics products supporting:
- COVID-19 surveillance  
- Measles outbreaks  
- Lassa Fever mapping  
- Emergency response  
- Capacity building  

---

## Components
- 6,000+ maps and dashboards  
- Geodatabase management  
- Spatial epidemiology outputs  

---

## Outputs
- Map gallery  
- Dashboard screenshots  
- Data schema summaries
