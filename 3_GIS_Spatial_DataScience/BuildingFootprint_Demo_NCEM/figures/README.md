# Publication figures

The corrected atlas and sensitivity figures are `wake-exposure-atlas`, `wake-exposure-details-mobile`, `wake-exposure-sensitivity` and `wake-exposure-sensitivity-mobile` (PNG and PDF). `figure_metadata.json` records the deterministic detail-window selection and histogram bins.

Older `flood_exposure_map*` files that remain in this repository predate the corrected county denominator, distinct-building counting and FEMA classification. They are historical artifacts and are superseded by the `wake-exposure-*` figures. See the project README and docs/CORRECTIONS.md.
