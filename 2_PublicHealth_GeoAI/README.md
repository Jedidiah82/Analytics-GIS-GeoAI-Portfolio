# Public Health GeoAI and Spatial Epidemiology

This pillar presents applied research and operational projects combining **GeoAI, spatial epidemiology, disease surveillance, explainable artificial intelligence, spatial statistics, and privacy-aware decision support**.

The work demonstrates how geospatial and epidemiological data can support disease forecasting, hotspot detection, outbreak-risk monitoring, public-health intelligence, and transparent operational decision-making.

## Flagship Project

### [Privacy-Preserving GeoAI Health Surveillance System](https://github.com/Jedidiah82/GeoAI-Health-Surveillance-System)

An end-to-end research prototype developed for the MSc Big Data Technologies dissertation:

> *Design and Evaluation of a Privacy-Preserving GeoAI Health Surveillance System Using a Hybrid Cloud Architecture*

The system transforms aggregated, de-identified district-level surveillance data into outbreak-risk classifications, spatial intelligence, explainable AI outputs, governance evidence, and dashboard-based decision support.

**Core capabilities:**

- GeoAI outbreak-risk prediction and classification
- Getis-Ord Gi* hotspot analysis and Local Moran's I cluster analysis
- XGBoost modelling with SHAP-based explainability
- Interactive Streamlit and Folium decision-support dashboard
- Secure FastAPI gateway with JWT authentication and role-based access control
- Audit logging and governance traceability
- Docker-based hybrid-cloud deployment workflow
- Privacy-preserving use of aggregated public-health surveillance data

**Technology stack:** `Python` `GeoPandas` `PySAL` `XGBoost` `SHAP` `Streamlit` `Folium` `FastAPI` `JWT` `RBAC` `Docker` `AWS`

**Project links:**

- [View the source repository](https://github.com/Jedidiah82/GeoAI-Health-Surveillance-System)
- [Open the public dashboard](https://geoai-health-surveillance-system-bygrraq7o4uwsfokny3lhg.streamlit.app/)

> The project is an academic research prototype using safe demonstration data. It is not intended for clinical diagnosis or operational deployment without further validation, security hardening, governance review, and institutional approval.

## Reproducibility and Data Governance

Project folders and linked repositories provide documentation, methods, code, figures, and safe demonstration data where appropriate. Restricted research data, trained artefacts, credentials, and sensitive operational files are excluded from public distribution.

Where source data cannot be shared because of privacy, licensing, ethical, or institutional restrictions, projects use synthetic or aggregated demonstration datasets and document the applicable access limitations.
